# 🎮 Погоняйло

**Погоняйло** — сборник весёлых мини-игр для компании до 4 человек за одним компьютером. В большинстве игр у каждого игрока **всего одна клавиша**: `Q`, `P`, `Z` или `M`. Свободные места занимают боты, а с друзьями на других компьютерах можно играть по локальной сети.

Игра работает на **Windows** и **macOS**. Интерфейс на русском языке.

> Текущая версия — **3.0.0**

## 🕹 Игры

| Игра | Описание | Управление (одна клавиша) |
|---|---|---|
| 🛡 **Танки 2D** | Арена с бонусами в ящиках и разрушаемыми стенами. Режимы: каждый сам за себя или команды | Держи — едешь · отпусти — разворот · короткий тап — выстрел |
| 🥋 **Сумо** | Круглые бойцы толкаются на сжимающейся платформе. Последний на арене побеждает | Отпущено — крутится стрелка · держи — заряд · отпусти — рывок |
| 🏓 **Пинг-понг на четверых** | Квадратное поле, у каждого своя сторона. Режимы «Жизни» и «Очки» | Держишь — ракетка едет вправо (вниз) · отпустил — влево (вверх) |
| 💣 **Артиллерия** | Пошаговая дуэль на разрушаемой земле с разными снарядами и суперударами | Нажми — угол · держи — сила · отпусти — выстрел · `1–4` — снаряд |
| 🐦 **Flappy Bird** | Кооператив: одна птица на всех (эстафета) или четыре птицы на одном экране | Нажатие — взмах |
| ❓ **Викторина** | Кто первым нажал свою клавишу, тот и отвечает. Можно добавлять свои колоды вопросов | Своя клавиша — «Я знаю!» · ответ мышью или цифрами `1–4` |
| 🔥 **Танки PvP (3D)** | Танки от первого лица: двое на одном ПК с разделённым экраном или по сети, плюс боты. Мини-карта, трава, кирпичные стены, настройка графики до «Ультра» | `W`/`↑`: держи — едешь, тап — выстрел · `A D`/`← →` — поворот · `S`/`↓` — назад |

**Клавиши игроков `Q · P · Z · M` работают и в русской раскладке.**

### Чем ещё богата игра

- **Боты** трёх уровней сложности на любом свободном месте.
- **Серии раундов** с таблицей очков и статистикой после каждого раунда.
- **Пауза** кнопкой в левом верхнем углу или клавишей `Esc`. В паузе можно поменять настройки или перезапустить игру.
- **Имена игроков** появляются рядом с персонажами во время отсчёта (Сумо, Танки 2D, Flappy Bird).
- **Свои колоды для викторины** хранятся в папке `Документы/Погоняйло`. Внутри есть пример и инструкция «КАК ДОБАВИТЬ СВОЮ КОЛОДУ.txt».

## 🌐 Игра по сети

1. Все компьютеры подключаются к одной сети: один Wi-Fi или один роутер.
2. Один игрок нажимает **«Игра по сети» → «Создать комнату»** и называет друзьям 4-буквенный код комнаты.
3. Остальные вводят этот код или выбирают комнату из списка найденных.
4. Кнопка **«+1»** в комнате добавляет ещё одного игрока с того же компьютера. В мини-играх так можно добавить до 4 игроков, в 3D-танках до 2 (`WASD` и стрелки).

Windows и Mac могут играть в одной комнате, но **версии игры у всех должны совпадать**.

Игра использует порты **TCP 41733** (игра) и **UDP 41734** (поиск комнат). Если Windows спросит про брандмауэр, разреши доступ в частных сетях.

## 💻 Установка

### Windows

Запусти `Pogonyaylo_Setup_3.0.0.exe` и следуй установщику. Если игра уже установлена, достаточно запустить патч `Pogonyaylo_Update_3.0.0.exe`.

Если появится окно «Windows защитил ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае». Окно появляется потому, что у установщика нет платной цифровой подписи.

### macOS (11 Big Sur и новее)

1. Распакуй архив и перетащи **«Погоняйло»** в папку «Программы».
2. Игра не заверена Apple (это платная услуга), поэтому при первом запуске macOS её заблокирует:
   - **macOS 15 Sequoia и новее:** «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
   - **Более старые версии:** правой кнопкой по игре → «Открыть» → «Открыть».
   - Если не помогло, выполни в Терминале:
     ```bash
     xattr -cr /Applications/Погоняйло.app
     ```
3. Когда Mac спросит про **доступ к локальной сети**, нажми «Разрешить», иначе игра по сети не заработает.

Полный экран на Mac переключается клавишами `⌃⌘F` или `F11`, выход — `⌘Q`.

## 🛠 Запуск из исходников

Нужен [Node.js](https://nodejs.org/) версии 18 или новее.

```bash
git clone https://github.com/Mari20004/Pogonyaylo.git
cd Pogonyaylo
npx electron@33.2.1 .
```

### Структура проекта

```
main.js              — главный процесс Electron: окно, полный экран, меню на Mac
package.json
app/
  index.html
  css/style.css      — оформление меню и интерфейса
  js/core.js         — общие функции, рисование, звук, хранение настроек
  js/runner.js       — игровой цикл 60 Гц, отсчёт, раунды, серии
  js/net.js          — сетевая игра: комнаты, поиск в локальной сети, синхронизация
  js/app.js          — меню, лобби, настройки, пауза
  js/games/          — сами игры: tanks, sumo, pong, artillery, flappy, quiz, tanks3d
  js/lib/three.min.js — three.js r158 для 3D-танков
```

### Как это устроено

- **Electron 33**: в окне работает обычная веб-страница с `<canvas>` (логическое разрешение 1920×1080, масштабируется под любой экран).
- 2D-игры рисуются через Canvas 2D, 3D-танки — через **three.js** (WebGL).
- Логика идёт фиксированными шагами по 60 раз в секунду, поэтому всё работает одинаково на любом компьютере.
- По сети главным считается компьютер хоста: он считает всю игру и 30 раз в секунду рассылает её состояние, а клиенты присылают только нажатия клавиш и плавно отрисовывают картинку.
